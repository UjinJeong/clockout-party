# 퇴근 파티 (clockout-party)

일에 지쳐 사람을 만날 힘은 없지만 심심한 사람이, 웹에서 3D 동물 캐릭터로 들어와
노는 파티입니다. 장소는 세 곳: 그림 전시장, 도시 아파트 홈파티, 바닷가 풀파티.

## 실행하기

Node.js 22 이상이 필요해요.

```bash
npm install          # 처음 한 번
npm run dev          # 서버(2567) + 웹(5173) 동시에 실행
```

브라우저에서 `http://localhost:5173` 을 열면 됩니다. 같은 와이파이의 휴대폰에서는
`http://내PC-IP:5173` 으로 들어오면 돼요. (음성 녹음은 https 또는 localhost에서만 동작합니다.)

장소를 점검할 때는 개발용 보기 화면을 쓰면 편해요(배포에는 포함되지 않음):
`http://localhost:5173/debug.html?theme=home&x=12&z=0&zoom=0&hour=21`
— 원하는 장소·위치·시각을 게임 카메라로 바로 보여 줘요.

| 명령 | 하는 일 |
|---|---|
| `npm test` | 규칙(shared) + 서버 테스트 |
| `npm run build` | 웹 클라이언트 빌드 → `client/dist` |
| `npm run build:demo -w client` | 서버 없이 도는 혼자 체험판 → `client/dist-demo` |
| `npm start` | 서버 실행 (빌드된 웹 화면도 같이 내보냄 → http://localhost:2567) |

웹을 다른 주소의 서버에 연결하려면 빌드할 때 `VITE_SERVER_URL=https://서버주소` 를 지정하세요.

**인터넷에 올리기(무료 방법 포함)는 [DEPLOY.md](DEPLOY.md)를 보세요.**

## 구조

```
shared/   서버와 웹이 같이 쓰는 규칙 (지도, 근처 판정, 입력 검사) — 나중에 Unity로 옮길 부분
server/   Colyseus 0.18 파티 서버 (방 = party)
client/   three.js + Vite 웹 화면
          └─ src/living/  「액자 밖으로」의 살아난 그림 방 (전시에서 그대로 가져옴, 자원은 public/a/)
docs/     설계 문서와 구현 계획
```

### 흐름

```
🎉 웹 파티
├─ 초대장 화면: 이름 + 동물 7종·색·머리·손·옷 꾸미기, 🎲 아무거나 (3D 미리보기)
├─ 로비
│   ├─ 열린 파티 목록 (5초마다 새로고침, 장소 아이콘 표시)
│   ├─ 새 파티 열기: 🖼️ 전시장 / 🏠 홈파티 / 🏖️ 풀파티 + 누구나 / 친구만
│   ├─ 초대 코드·링크로 들어가기
│   └─ 서버 없이 혼자 체험하기 (봇 손님)
└─ 파티장
    ├─ 🖼️ 전시장: 로비·정원관·얼굴관·장난감관·연못관 (벽 그림이 방마다 은은하게 움직임)
    ├─ 🏠 홈파티: 거실(벽난로·레코드)·부엌(피자·케이크)·테라스(도시 야경·그릴)
    ├─ 🏖️ 풀파티: 바 오두막·수영장(들어가면 튜브 타고 둥둥 🛟)·모래사장(DJ·모닥불)
    ├─ 걷기: 방향키/WASD, 바닥 클릭·탭, 휴대폰 조이스틱
    ├─ 카메라: 동물의 숲처럼 뒤에서 따라오는 가까운 시점 ↔ 멀리 보기 (버튼·V키·휠·두 손가락)
    ├─ 발밑의 빛나는 원(반경 4.5m) 안 사람에게만
    │   ├─ 💬 텍스트 말풍선
    │   ├─ 🥂😂👏❤️😮👋 이모지 + 캐릭터 동작
    │   └─ 🎤 음성 말풍선 (최대 30초, 눌러서 듣기, 서버에 저장 안 함)
    ├─ 🔋 충전 중 / 🪫 방전 상태 표시 (방전이면 눈꺼풀도 더 무거워요)
    ├─ 그림 앞에 서면 「살아난 그림 보기」 → 전시의 움직이는 그림 방
    │   └─ 그림마다 다른 움직임(바람, 나비, 잉어, 낮·밤…) + 해 보기 + 도슨트
    ├─ 하늘 = 내가 접속한 곳의 지금 시각 (새벽·아침·낮·노을·밤)
    │   └─ 실내는 창문·테라스 너머로만, 풀파티는 하늘 전체
    └─ 사람들 목록에서 특정 사람 안 보기(음소거)
```

## 관리 페이지

서버를 켜면 콘솔에 주소와 비밀번호가 나와요.

```
🔑 관리 페이지: http://localhost:2567/admin
```

- 비밀번호를 고정하려면 서버를 켤 때 `ADMIN_PASSWORD=원하는비밀번호` 를 지정하세요. (안 정하면 켤 때마다 새로 만들어져요)
- 보이는 것: 지금 접속 수, 오늘 방문 수·최대 동시 접속·평균 머문 시간, 지역별 접속, 최근 7일 방문, 열린 파티(친구만 방 포함), 지금 있는 사람, 최근 나간 사람
- 지역은 IP가 아니라 기기의 시간대 설정으로 알아낸 대략적인 곳 (개인정보 저장 없음)
- 방문 기록은 `server/data/visits.jsonl` 에 쌓여서 서버를 껐다 켜도 남아요 (31일 보관)
- 더 자세한 방·연결 정보: `/admin/monitor` (Colyseus 모니터)

## 서버가 지키는 규칙

- 한 방 최대 20명, 닉네임 12자, 채팅 120자
- 순간이동처럼 빠른 이동은 거절하고 원래 자리로 되돌림(`snap`)
- 벽·칸막이·바·의자는 서버도 같은 지도로 막음
- 채팅·이모지·음성은 **보낸 사람 근처에 있는 사람에게만** 전달
- 친구만 방은 목록(`GET /rooms`)에 안 보이고, 방 ID가 곧 초대 코드
