# 웹 파티 첫 버전 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 「액자 밖으로」 전시관에서 여러 사람이 3D 동물 캐릭터로 만나 근처 채팅·이모지·음성 말풍선으로 노는 웹 파티 첫 버전.

**Architecture:** npm workspaces 모노레포. `shared`(순수 규칙 함수) ← `server`(Colyseus 0.18 `party` 방, 근처 판정으로 메시지 선별 중계) ← `client`(Vite + three.js, 네트워크 연결은 `PartyConnection` 인터페이스 뒤에 숨기고 Colyseus/데모 두 구현).

**Tech Stack:** Node 22, TypeScript 5, Colyseus 0.18 (`colyseus`, `@colyseus/schema` 5 `schema()` 문법, `@colyseus/sdk`, `@colyseus/testing`), three.js 0.187, Vite 8, Vitest.

**Spec:** `docs/superpowers/specs/2026-11-10-web-party-design.md`

## Global Constraints

- 방 최대 인원 20, 근처 반경 4.5m, 채팅 최대 120자, 닉네임 1~12자
- 음성: 최대 30초, 최대 400KB, mime은 `audio/`로 시작
- 이동 최대 속도 3.2m/s (클라이언트 걷기 2.6m/s)
- 이모지 종류: `cheers 🥂, laugh 😂, clap 👏, heart ❤️, wow 😮, wave 👋`
- 캐릭터: 종류 `bear|cat|penguin|rabbit`, 색 팔레트 8색 인덱스 0~7, 소품 `none|wine|beret|ribbon`
- 배터리: `charging`(충전 중: 말 걸어도 돼) | `low`(방전: 구경만 할래)
- 전시관 좌표: 방 5칸(로비·정원관·얼굴관·장난감관·연못관), 칸당 x 12m × z 10m, x ∈ [0,60], z ∈ [-5,5], 칸막이 x=12,24,36,48, 문 폭 4m(|z|<2)
- UI 문구는 한국어, 서버는 잘못된 메시지를 조용히 버림
- 녹음은 서버에 저장하지 않고 중계만

```ts
// shared/test/world.test.ts
import { describe, it, expect } from 'vitest';
import { moveWithCollision, isWalkable, roomAt, isNear, nearbyIds, SPAWN } from '../src';
describe('world', () => {
  it('spawn is walkable', () => expect(isWalkable(SPAWN)).toBe(true));
  it('blocks walking through a partition outside the doorway', () => {
    const p = moveWithCollision({ x: 11, z: -4 }, { x: 13, z: -4 });
    expect(p.x).toBeLessThan(12);
  });
  it('lets you through the doorway', () => {
    const p = moveWithCollision({ x: 11.5, z: 0 }, { x: 12.5, z: 0 });
    expect(p.x).toBeCloseTo(12.5);
  });
  it('clamps to the back wall', () => {
    expect(moveWithCollision({ x: 6, z: -4 }, { x: 6, z: -9 }).z).toBeGreaterThan(-5);
  });
  it('roomAt', () => { expect(roomAt(3)).toBe('lobby'); expect(roomAt(50)).toBe('pond'); });
});
describe('proximity', () => {
  it('near within radius', () => expect(isNear({ x: 0, z: 0 }, { x: 3, z: 3 })).toBe(true));
  it('far outside radius', () => expect(isNear({ x: 0, z: 0 }, { x: 5, z: 0 })).toBe(false));
  it('nearbyIds includes self', () => {
    const a = { id: 'a', x: 0, z: 0 }, b = { id: 'b', x: 1, z: 0 }, c = { id: 'c', x: 20, z: 0 };
    expect(nearbyIds(a, [a, b, c]).sort()).toEqual(['a', 'b']);
  });
});
```

  - 메타데이터 `{ title, theme:'gallery', private:boolean }`, HTTP `GET /rooms` → `[{roomId,title,clients,maxClients}]`(공개·잠기지 않은 방만)

```ts
// server/test/party.test.ts
import { describe, it, expect, beforeAll, afterAll, afterEach } from 'vitest';
import { boot, type ColyseusTestServer } from '@colyseus/testing';
import app from '../src/app';
let colyseus: ColyseusTestServer;
beforeAll(async () => { colyseus = await boot(app); });
afterAll(async () => { await colyseus.shutdown(); });
afterEach(async () => { await colyseus.cleanup(); });
const look = { kind: 'cat', color: 2, prop: 'wine' };
const wait = (ms: number) => new Promise(r => setTimeout(r, ms));
describe('party room', () => {
  it('adds a player with sanitized name and look', async () => {
    const room = await colyseus.createRoom('party', { title: '테스트' });
    const c = await colyseus.connectTo(room, { name: '  유진 ', look });
    await room.waitForNextPatch();
    const p = room.state.players.get(c.sessionId)!;
    expect(p.name).toBe('유진'); expect(p.kind).toBe('cat');
  });
  it('delivers chat only to nearby players', async () => {
    const room = await colyseus.createRoom('party', {});
    const a = await colyseus.connectTo(room, { name: 'A', look });
    const b = await colyseus.connectTo(room, { name: 'B', look });
    const far = await colyseus.connectTo(room, { name: 'C', look });
    const got: Record<string, string[]> = { a: [], b: [], far: [] };
    a.onMessage('chat', m => got.a.push(m.text)); b.onMessage('chat', m => got.b.push(m.text)); far.onMessage('chat', m => got.far.push(m.text));
    room.state.players.get(far.sessionId)!.x = 55; // 연못관으로 순간이동
    a.send('chat', { text: '안녕' }); await wait(150);
    expect(got.a).toEqual(['안녕']); expect(got.b).toEqual(['안녕']); expect(got.far).toEqual([]);
  });
  it('rejects teleport moves and snaps back', async () => {
    const room = await colyseus.createRoom('party', {});
    const a = await colyseus.connectTo(room, { name: 'A', look });
    let snapped = false; a.onMessage('snap', () => { snapped = true; });
    await wait(50); a.send('move', { x: 58, z: 0, dir: 0, moving: true }); await wait(150);
    expect(snapped).toBe(true); expect(room.state.players.get(a.sessionId)!.x).toBeLessThan(12);
  });
  it('relays a voice note to nearby players only, and drops oversize ones', async () => {
    const room = await colyseus.createRoom('party', {});
    const a = await colyseus.connectTo(room, { name: 'A', look });
    const b = await colyseus.connectTo(room, { name: 'B', look });
    const sizes: number[] = []; b.onMessage('voice', m => sizes.push(m.data.byteLength));
    a.send('voice', { mime: 'audio/webm', ms: 1500, data: new Uint8Array(1000) });
    a.send('voice', { mime: 'audio/webm', ms: 1500, data: new Uint8Array(500_000) });
    await wait(200); expect(sizes).toEqual([1000]);
  });
  it('hides private rooms from the listing', async () => {
    await colyseus.createRoom('party', { title: '공개', private: false });
    await colyseus.createRoom('party', { title: '비밀', private: true });
    const res = await colyseus.http.get('/rooms');
    const titles = (res.data as any[]).map(r => r.title);
    expect(titles).toContain('공개'); expect(titles).not.toContain('비밀');
  });
});
```

```ts
  battery(level: Battery): void; leave(): void;
}
```
