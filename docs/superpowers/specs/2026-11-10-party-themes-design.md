# 파티 장소(테마) 설계 — 🖼️ 전시장 · 🏠 홈파티 · 🏖️ 풀파티

## 목표
방을 만들 때 파티 장소를 고른다. 장소마다 걸어 다닐 수 있는 곳, 가구, 분위기가 다르다.
서버와 화면은 같은 지도를 쓴다. 그래서 부딪힘 판정이 어긋나지 않는다.

## 구조
```
공통(shared/world.ts)
 ├─ WorldMap = { bounds, rooms, walls, obstacles, water, spawn, spots }
 ├─ MAPS.gallery / MAPS.home / MAPS.pool  (데이터일 뿐)
 └─ isWalkable · moveWithCollision · nearestWalkable · roomAt · inWater (모두 지도를 받음, 기본값은 전시장)
서버(PartyRoom)
 ├─ 방 만들 때 theme 옵션 → state.theme + 목록 metadata
 └─ 이동 판정은 그 방의 지도로
화면(client)
 ├─ World 인터페이스: map · paintings · floor · setTime · tick · fadeOccluders · loadArt · dispose
 ├─ buildWorld(theme) → gallery.ts / home.ts / pool.ts
 ├─ main.ts: 접속한 방의 theme에 맞춰 세계를 갈아 끼움 (useWorld)
 └─ party.ts: 지도로 걷기, 수영장 물(water) 안이면 튜브 타고 둥둥
```

## 장소별 구성
- **홈파티** (0–36m): 거실(소파·벽난로·러그·레코드 플레이어·창밖 하늘), 부엌(카운터·냉장고·아일랜드 위 피자/케이크/파티컵·펜던트 조명·현수막), 테라스(데크·빈백·그릴·전구 줄·멀리 보이는 도시 야경).
  - 실내 위쪽은 어두운 배경이다.
  - 하늘은 창문과 테라스 너머에만 보인다.
- **풀파티** (0–40m): 바 오두막(초가 지붕·칵테일·티키 횃불), 수영장(선베드·야자수·떠다니는 플라밍고/도넛/비치볼), 모래사장(파라솔·DJ 부스·모닥불).
  - 야외라서 배경 전체가 접속한 시각의 하늘이고, 뒤로 바다가 지평선까지 펼쳐진다.
  - 키가 큰 물건은 뒤쪽에만 둔다. 앞에 두면 카메라를 가리기 때문이다.

## 고르는 곳
- 서버 모드: 로비 "새 파티 열기"에서 장소를 고른다. 목록에는 장소 아이콘과 이름이 나온다. "혼자 체험하기"는 고른 장소로 들어간다.
- claude.ai 페이지(로비 없음):
  - 초대장에 "파티 장소" 줄이 있다. 고르면 뒤 배경이 그 장소로 바뀐다.
  - 같은 장소를 고른 사람끼리 만난다. 전시장은 기본 방, 홈/풀은 `room.join(theme)`으로 들어가는 이름 붙은 방이다.

## 봇
장소마다 모이는 자리(spots)가 다르고, 하는 말(LINES)도 다르다. 풀파티 봇은 물에도 들어간다.

## 테스트
- 지도:
  - 각 장소마다: 출발점이 걸을 수 있는 곳인지, 방이 끊김 없이 이어지는지, 가구가 지도 안에 있는지.
  - 모든 모이는 자리와 모든 방에 출발점에서 실제로 걸어갈 수 있는지(격자를 채워서 확인).
  - 물에는 들어갈 수 있고, 물로 판정되는 곳은 수영장뿐인지.
- 서버: theme 동기화, 모르는 theme는 전시장으로, 장소별 벽 판정, 목록에 theme가 나오는지.
- 화면: 페이지 id 검사, 캐릭터 옷장 검사(기존).
