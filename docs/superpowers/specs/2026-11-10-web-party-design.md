# 웹 파티 — 첫 버전 설계 (「액자 밖으로」 오프닝 파티)

- 작성일: 2026-11-10
- 상태: 승인됨 (사용자가 방식 B 승인 후 "스스로 진행" 요청)

## 1. 목적

일에 지쳐 사람을 직접 만날 힘은 없지만 심심한 사람이, 웹에서 가볍게 들어와 3D 캐릭터로
파티에 섞이는 서비스. 첫 버전은 **테마 1개(정유진 개인전 「액자 밖으로」 오프닝 파티)**로
"같이 있는 느낌이 재밌는가"를 확인하는 것이 목표다.

### 성공 기준
1. 두 사람 이상이 같은 방에 들어와 서로의 캐릭터가 움직이는 것을 본다.
2. 가까이 있는 사람끼리만 텍스트·음성 말풍선과 이모지가 보인다/들린다.
3. 공개방은 목록에서 골라 입장, 친구방은 초대 링크(코드)로만 입장한다.
4. PC 브라우저와 휴대폰 브라우저 모두에서 조작 가능하다.
5. 창밖 하늘과 조명이 각자 접속한 지역의 현재 시각을 따른다.

## 2. 범위

| 첫 버전에 포함 | 다음 단계로 미룸 |
|---|---|
| 전시관 테마(로비 + 정원관·얼굴관·장난감관·연못관) | 홈파티·풀파티 테마 |
| 가벼운 3D 동물 캐릭터 고르기(종류·색·소품) | 캐릭터 상점·세부 꾸미기 |
| 근처 텍스트 말풍선, 이모지 반응(+동작) | 귓속말(1:1 음성/텍스트) |
| 근처 음성 말풍선(최대 30초, 누르면 재생) | 실시간 음성 통화 |
| 🔋 상태 표시(충전 중 / 방전) | 로그인·친구 목록 |
| 공개방 목록 / 친구방 초대 링크 | 신고 기능(차단은 개인 음소거로 대체) |
| 그림 앞에서 작품 정보·도슨트 해설 보기 | 살아 움직이는 그림 효과, 같이 맞추는 퍼즐 |
| 서버 없이 볼 수 있는 데모 모드(봇 손님) | 배포 자동화 |

## 3. 구조

```
web-party/
├─ shared/   방·메시지 규칙(상수, 근처 판정, 검증) — 서버와 클라이언트가 같이 씀
├─ server/   Colyseus 서버 (Node.js, TypeScript)
└─ client/   three.js + Vite 웹 클라이언트
```

### 3.1 shared — 규칙 한곳에 모으기
- `constants`: 방 최대 인원 20, 근처 반경 4.5m, 채팅 120자, 음성 30초·최대 400KB, 이동 속도 등
- `proximity(a, b)`: 두 위치가 근처인지
- `validate*`: 닉네임/채팅/이모지/캐릭터 설정 검사(서버가 최종 판정)
- `world`: 전시관 바닥 영역(걸을 수 있는 범위)과 벽 충돌 판정 — 서버와 클라이언트가 같은 지도를 씀
- 나중에 Unity 버전이 같은 규칙을 C#으로 옮길 수 있도록 순수 함수만 둔다.

### 3.2 server — Colyseus `party` 방
- 방 상태(모두에게 동기화): 플레이어 목록 `{id, name, look(종류·색·소품), x, z, dir, moving, battery}`
- 방 메타데이터(목록용): `{title, theme, isPrivate, count}`
- 비공개 방은 `setPrivate()`로 목록에서 숨기고, 방 ID를 초대 코드로 사용
- 메시지
  - `move {x, z, dir, moving}`: 서버가 걸을 수 있는 범위로 보정하고, 너무 빠른 이동은 거절
  - `chat {text}`: 서버가 **보낸 사람 근처에 있는 사람에게만** 전달
  - `emote {kind}`: 근처에만 전달(이모지 종류는 정해진 목록)
  - `voice {bytes, mime, ms}`: 크기·길이 검사 후 근처에만 전달. 서버는 저장하지 않고 바로 중계 → 방이 끝나면 아무것도 안 남음
  - `battery {level}`: 충전 중/방전 전환
- 방은 마지막 사람이 나가면 자동 정리

### 3.3 client — three.js
- **장면**: 원작 전시관의 색(로비 갈색, 정원 초록, 얼굴 와인, 장난감 남색, 연못 청록)과 쪽모이 바닥을 이어받은 5칸 갤러리. 위에서 비스듬히 보는 시점이라 **카메라 쪽 벽은 없애고**(디오라마) 안쪽 벽·칸막이에 그림을 건다. 로비에는 와인 바와 큰 창.
- **현지 시각**: 접속 기기의 시각으로 창밖 하늘색·조명 세기·색온도를 정한다(새벽·낮·노을·밤 4단계 보간).
- **캐릭터**: 기본 도형으로 조립한 로우폴리 동물(곰·고양이·펭귄·토끼). 공통 팔레트 색, 소품(와인잔·베레모·리본·없음). 걷기/대기/이모지 동작은 코드 애니메이션(뼈대·외부 모델 파일 없음 → 매우 가벼움).
- **조작**: PC는 방향키·WASD, 모두 공통으로 바닥 클릭/탭하면 그 자리로 걸어감, 휴대폰은 화면 조이스틱.
- **말풍선**: 캐릭터 머리 위 HTML 말풍선(텍스트 6초, 음성은 ▶ 버튼). 근처 대화 무리를 바닥의 은은한 원으로 표시.
- **그림 보기**: 그림 앞에 서면 "작품 보기" 버튼 → 작품명·설명·도슨트 해설 패널.
- **화면 흐름**: 시작(닉네임·캐릭터) → 로비 화면(공개방 목록 / 새 방 만들기 / 초대코드 입장) → 파티.
- **데모 모드**: 서버에 연결할 수 없으면 봇 손님 몇 명이 돌아다니고 말을 거는 혼자 체험판으로 자동 전환.

## 4. 데이터 흐름

```
내 입력(키·탭) → 내 캐릭터 즉시 이동(예측) → 10Hz로 서버에 move
서버 → 보정된 위치를 상태로 동기화 → 다른 사람 화면에서 부드럽게 보간
채팅/이모지/음성 → 서버 → 근처 판정 → 근처 사람에게만 전달 → 말풍선
```

## 5. 오류 처리

- 서버 연결 실패: 데모 모드로 전환하고 화면 위에 "혼자 체험 중" 표시
- 연결이 끊김: 자동 재연결 시도, 실패하면 로비로 돌아가기 안내
- 마이크 권한 거부/미지원: 녹음 버튼을 숨기고 안내 문구
- 방 인원 초과/초대코드 오류: 로비에서 이유를 알려줌
- 잘못된 메시지: 서버가 조용히 버림(클라이언트를 끊지 않음), 이동 위반은 위치 되돌림

## 6. 테스트

- shared: 근처 판정, 걸을 수 있는 범위, 입력 검증 단위 테스트
- server: 실제 서버를 띄우고 테스트 클라이언트 2~3명을 접속시켜 확인
  (근처 사람만 채팅·음성을 받는지, 비공개 방이 목록에서 숨는지, 이동 보정, 인원 제한)
- client: 빌드 성공 + 헤드리스 브라우저로 데모 모드 화면 캡처해 눈으로 확인

## 7. 나중에 Unity 버전

서버(Colyseus)는 그대로 두고 Unity 클라이언트가 Colyseus Unity SDK로 같은 방에 접속한다.
shared 규칙과 메시지 이름은 그대로 C#으로 옮긴다. 웹과 Unity 사용자가 한 파티에 같이 있을 수 있다.
